## Overview
HyperPulse Grid is an AI-native automated trading strategy for Hyperliquid. It utilizes the Agentic Wallet's Pilot Mode to execute high-frequency grid trades, maximizing transaction volume and count for the user.

## Prerequisites
- OKX Wallet with active Agentic Wallet setup.
- USDC on Arbitrum (for Hyperliquid collateral).
- Authorization for Pilot Mode (Session permissions).

## Quick Start
1. Ask the agent: "Open HyperPulse Grid dashboard."
2. Set your price range (Upper and Lower).
3. Toggle **Pilot Mode** to ON to start automated trading.
