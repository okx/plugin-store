## Step 5 — Live test (OPTIONAL — requires funds)

**Live funds needed:** ✅ YES — small amount of ETH for gas + deposit

### G3 live-test matrix

| Tool | Class | Pre-state needed | Live cost | Reversibility | G3 recommendation |
|------|-------|------------------|-----------|---------------|-------------------|
| `getApr` | Read | none | none | n/a | N/A — covered by Step 3 (B-real) |
| `getProtocolStats` | Read | none | none | n/a | N/A — covered by Step 3 (B-real) |
| `getEzethRate` | Read | none | none | n/a | N/A — covered by Step 3 (B-real) |
| `previewWithdraw` | Read | none | none | n/a | N/A — covered by Step 3 (B-real) |
| `listWithdrawRequests` | Read | none | none | n/a | N/A — covered by Step 3 (B-real) |
| `buildDepositEth` | Tx-single | none | gas (~$1) + value (≥0.005 ETH recommended) | instant (sell ezETH on Curve/Balancer for ETH) | ✅ live-test with min deposit |
| `buildRequestWithdraw` (approve step) | Tx-approve | none | gas only (~$1) | revoke via separate `ezETH.approve(WithdrawQueue, 0)` | ✅ cheap-validate; also confirms multi-step state machine emits step 2 on re-invocation |
| `buildRequestWithdraw` (withdraw step) | Tx-multi-step | approve from step 1 + ezETH balance ≥ amount | gas (~$1) + locks burned ezETH for ~15d | soft-15d (claim after EigenLayer 14d unstake + Renzo 3d buffer) | ⚠️ commit-funds only if 15d-tolerant; smallest sensible test is 0.001 ezETH |
| `buildClaimWithdraw` | Tx-single | matured withdraw request (≥15d after step 2) | gas only (~$1) | n/a (releases locked stETH/ETH back to user) | ❌ not testable until a `buildRequestWithdraw` matures — schedule a follow-up session |

### Choosing the G3 scope

Default: test every ✅ row, ask before any ⚠️ row, surface ❌ rows with their re-test schedule. For v0.1.0 baseline coverage, the cheapest-and-most-thorough G3 is the **approve+deposit pair** (~$2 gas total) — it validates ~50% of the write-path surface without locking any value.

### Prerequisites
- Onchainos wallet logged in: `onchainos wallet login your@email.com && onchainos wallet verify <otp>`
- Funded wallet on Ethereum mainnet (≥0.02 ETH: 0.01 deposit + 0.01 gas cushion)
- User has EXPLICITLY OPTED IN via the conversation

### Recommended live path (smallest-impact only — no full withdraw cycle)

Live testing the full deposit → withdraw cycle is **not recommended** because the withdraw cooldown is ~15 days. The reasonable live test is the deposit half only:

1. `buildDepositEth({amount: "0.01"})` → `pending_sign`
2. Broadcast via `onchainos wallet contract-call --chain ethereum --to 0x74a09653... --input-data <data> --amt 10000000000000000 --biz-type defi --strategy renzo-onchainos --force`
3. Verify the user received ezETH (`erc20.balanceOf(EZETH, wallet)` increased by ≈ `0.01 / rate`)

For `buildRequestWithdraw` + `buildClaimWithdraw`, defer live testing to a separate "patience pass" 15+ days after the request is queued, or rely on Step 2/3/4 dry-run validation only.

### Live broadcast pattern (after pending_sign is built):

```bash
onchainos wallet contract-call \
  --chain ethereum \
  --to <unsigned_tx.to> \
  --input-data <unsigned_tx.data> \
  --amt <unsigned_tx.value> \
  --biz-type defi \
  --strategy renzo-onchainos \
  --force
```

> Note: `--input-data` (NOT `--data`) and `--amt` (NOT `--value`) — these are the
> real onchainos CLI flag names. Verified live 2026-05-11.

## Skipping live tests

If the developer doesn't have a funded mainnet wallet, **stop at Step 4**. v0.1.0 is designed so steps 1-4 produce a "serviceable plugin" without any live requirements.
