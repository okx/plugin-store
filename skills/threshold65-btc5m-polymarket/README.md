# Threshold65 BTC5M Polymarket

This is the contest-compliant Strategy Skill adaptation of the local BTC 5-minute threshold strategy.

The original local live bot used direct Polymarket CLOB execution. This public Plugin Store submission intentionally routes all trading through `polymarket-plugin` with `--strategy-id threshold65-btc5m-polymarket` so usage can be attributed for the Plugin Store DApp contest.
