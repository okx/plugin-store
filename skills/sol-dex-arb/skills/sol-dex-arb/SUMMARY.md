# sol-dex-arb
## Overview
SOL arbitrage strategy on Raydium DEX.
Core operations:
- Monitor SOL/USDC price
- Execute trades when profitable
Tags: `solana` `strategy` `raydium`
## Prerequisites
- raydium-plugin installed
- Funded Solana wallet
## Quick Start
1. Run `python3 scripts/arb.py` to start monitoring and trading.
