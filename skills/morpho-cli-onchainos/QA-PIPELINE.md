Confirm all 16 tools return well-formed JSON. No raw exceptions.

## Step 3 — Live CLI wiring (B-real)

The Morpho CLI is the runtime; there is no SDK to wire. Just flip the env var:

```bash
MORPHO_RUNTIME=real npx tsx cli.ts healthCheck '{}'
MORPHO_RUNTIME=real npx tsx cli.ts queryVaults '{"chain":"base","limit":3}'
MORPHO_RUNTIME=real npx tsx cli.ts getMarket '{"chain":"base","id":"<real-32-byte-id>"}'
```

The first call will trigger `npx` to download `@morpho-org/cli@latest`. Subsequent calls run from npx's cache.

Decode the `unsigned_tx.data` from a `prepareDeposit` result and confirm the function selector looks plausible (e.g., starts with `0x6e553f65` for ERC4626 `deposit(uint256,address)` or `0x095ea7b3` for the bundled approve).

## Step 5 — Live test (OPTIONAL — requires funds)

### Prerequisites
- Onchainos wallet logged in
- Funded wallet on Base (or pick another supported chain) with ~$2 in USDC + ~$0.50 in native ETH for gas
- User has EXPLICITLY OPTED IN

### Live broadcast pattern

```bash
onchainos wallet contract-call \
  --chain base \
  --to <unsigned_tx.to> \
  --input-data <unsigned_tx.data> \
  --amt <unsigned_tx.value> \
  --biz-type defi \
  --strategy morpho-cli-onchainos \
  --force
```

> `--input-data` (NOT `--data`) and `--amt` (NOT `--value`). Verified live 2026-05-11.
